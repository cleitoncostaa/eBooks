## Governance

This repository should only contain content that is clearly allowed to be public:

- Original material created by the repository owner.
- Public-domain material.
- Openly licensed material with license terms preserved.
- Material with explicit redistribution permission.

If license or redistribution rights are uncertain, the file should not remain in a public repository. Make the repository private or remove the file from the public tree after confirming the correct handling.

## Organization Rules

- Keep one topic per folder under `ebooks/`.
- Keep a short `README.md` inside each topic folder.
- Do not add credentials, personal notes, private annotations or account data.
- Prefer links to official sources when redistribution is not explicitly allowed.
